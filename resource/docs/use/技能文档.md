# Skill 文档

NeoForge 版本会从 `config/neuracraft/skills/` 递归读取 `SKILL.md`。每个 skill
目录可以继续包含参考资料，但只有名为 `SKILL.md` 的文件会被注册。

文件必须以 front matter 开始：

```markdown
---
name: minecraft-weather
description: 查询和解释 Minecraft 天气
triggers: [天气, weather, 下雨]
always: false
---
# 天气

调用天气工具获取实时结果，再用简洁中文回答。
```

字段说明：

- `name` 和 `description` 必填，`name` 在所有 skill 中必须唯一。
- `triggers` 和 `keywords` 可选，用于根据用户问题选择 skill；两者会合并。
- `always: true` 会让 skill 在每次相关模型请求中注入。
- front matter 后的 Markdown 正文是实际注入模型的操作说明。

服务器启动时会加载 skill。运行期间新增或修改 `SKILL.md` 后，下一次模型请求
会自动刷新索引。单个文件解析失败不会影响已经成功加载的其他 skill，错误会写入
日志；上下文注入会限制数量和总字符数，避免占满模型上下文。

skill 会追加到 DeepSeek 和 GPT 的 system context，不会修改银影的原有
`systemPrompt`。工具调用的后续轮次会继续使用原问题选择出的 skill，不会把工具
结果重新当作用户问题。
